一、排名规则怎么设计 The Ranking Rule

需求很直接：按 PV、UV、转发分享、点赞 的数量给文章排名。但真跑一遍数据就会发现一个尴尬的事实——这四个数，绝大多数平台并不公开：微信公众号只给到「阅读 / 在看」，头条与腾讯新闻的计数由 JS 动态加载抓不到，Substack 只公开点赞评论分享，海外媒体几乎只给 HN 点数。所以这条规则必须回答两个问题：不同平台的数怎么可比，以及缺了的数怎么补。

最终规则分四层：

Score = 100 × ( 0.30·PV̂ + 0.20·UV̂ + 0.30·SĤ + 0.20·LK̂ ) × A × R
PV̂ / UV̂ / SĤ / LK̂：四项指标经 log₁₀ 对数压缩后，在候选池内归一化到 [0, 1]　·　A：平台权威系数　·　R：时效衰减

第一层，权重。转发分享的成本远高于点赞——点赞是「不错」，转发是「我拿自己的信用背书」，所以转发的权重（0.30）必须压过点赞（0.20）；PV 管触达广度，UV 管去重后的真实受众深度，两者合计占一半，互动合计占一半：

维度权重为什么
PV 阅读量0.30触达规模，决定「有多少人可能看过」；但可能来自平台分发而非认可，故不独占最高权重。
UV 独立访客0.20去重后的真实受众；防刷量，衡量人群深度而非曝光次数。
转发 / 分享0.30最高成本的社会背书（公开以自己的名义推荐），与 PV 同权。
点赞 / 赞同0.20低成本认可，信号真实但最廉价，权重最低。

第二层，对数归一化。互动数据是典型的长尾分布：头部文章的点赞可以是腰部的一百倍，直接线性归一化会让第 2 名到第 18 名全部挤在 0 附近。取 X̂ = log₁₀(x+1) / log₁₀(max+1) 做池内归一化：既压缩头部、保住排序，又不会让量级差异彻底消失。

第三层，平台权威系数 A。同样一万阅读，发在红杉官网和发在聚合站上的信息价值不同。A 取值：一手信源（Sequoia / Block、Mollick 的 One Useful Thing）1.10–1.15；头部科技媒体（极客公园）1.05；机构媒体（腾讯新闻、凤凰网、中新网）1.00；垂直社区（人人都是产品经理、InfoQ、今日头条）0.95–1.00；转帖与行业稿 0.85–0.90。系数只用于裁决同量级文章，不改变数量级。

第四层，时效衰减 R。取 R = 0.5^(天数/365)——一年的半衰期。这是为「阅读清单」场景特意调松的：榜单内容以常青思考为主，经典老文不该被几周内的热文彻底埋掉（若做新闻式热榜，半衰期应缩到 90 天以内）。

数据成色图例：● 实测 = 平台公开可查（Substack 的点赞 / 评论 / 分享为页面公开数据）；◐ 代理 / 估算 = 平台未公开该指标，按平台量级与行业互动率估算，仅用于进入公式、不影响文章真实性。PV / UV 两列全部为 ◐——这正是本规则要用「权威 + 策展」兜底的原因。

From Hierarchy to Intelligence

从层级到智能：用 AI 取代中层协调

给出一个不掺水的 AI Native 定义：不是买了多少模型、开了多少账号，而是每条流程都重新回答过三个问题——哪些活让 AI 先干、哪些判断必须人来拍、哪些结果必须有人核过——并且岗位说明、绩效、审批、人才结构都按答案改写。企业转型三级台阶：替换（一比一换人）→ 增强（人人配 Copilot，局部效率）→ 重构（围绕「活儿怎么流转」重画组织）。

Making AI Work: Leadership, Lab, and Crowd

Ethan Mollick · One Useful Thing (Substack) · 2025-05-22 · 规则分 33.1（被时效衰减压低）

解释那个扎心的事实：员工个人用 AI 效率暴涨，公司整体却看不到收益——因为组织级增益需要组织级创新，而这套肌肉早已萎缩（外包给了咨询公司和软件商）。解法是三件套：Leadership（画出 AI 时代的具体图景，而不是发备忘录）、Lab（跨职能快速试验）、Crowd（把「Secret Cyborgs」——偷偷用 AI 的员工——请出阴影）。

四、局限与复跑方法 Caveats & How to Re-run

诚实交代三件事。其一，PV / UV 在所有候选平台均不公开，表中两列是平台量级代理估算，只影响相对分差不影响文章真伪；Substack 的点赞 / 评论 / 分享与 HN 点数为公开实测。其二，权威系数 A 与半衰期 R 是规则参数而非数据——换成 90 天半衰期，榜单会向近三个月热文倾斜；A 的取值见第一节，可辩。其三，样本 18 篇来自中英文公开检索（平台检索 + 站内热度），不等于全网全集；「值得读」的最终裁决是规则分 × 编辑判断，后者标注在卡片里。

复跑方法。这条规则是模板：把你自有数据（GA / 神策 / 新榜 / 公众号后台）的 PV、UV、转发、点赞四列替换进公式即可，权重（0.30 / 0.20 / 0.30 / 0.20）、对数归一化与 A、R 三个参数都可以按你的场景调。若某项指标缺失，建议置为该指标在池内的中位数并在表中标注，而不是悄悄丢掉——缺数本身也是信息。
